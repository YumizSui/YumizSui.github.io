I built a VS Code / Cursor [extension](https://marketplace.visualstudio.com/items?itemName=yumizsui.tex-review) that lets you comment on LaTeX manuscripts as you would in Overleaf or Word, then ask an AI assistant to make revisions.

Comments appear beside the text you select. You can edit with the TeX source and PDF side by side, and ask an AI assistant to read your comments and make changes.

<img src="/blog/tex-review-studio/review-workflow.gif" alt="Adding comments and revising a manuscript" width="960">

The extension is available on the [Marketplace](https://marketplace.visualstudio.com/items?itemName=yumizsui.tex-review), so you can find and install it by searching for `TeX Review Studio`. The source code and usage instructions are on [GitHub](https://github.com/YumizSui/tex-review).

Incidentally, I wrote this post using the extension to add comments as I went.
